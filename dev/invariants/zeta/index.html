Zeta function

Let $X$ be a smooth projective hypersurface of dimension $m$ over $\mathbb{F}_q$. Its zeta function records the point counts over finite extensions of $\mathbb{F}_q$:

\[Z(X,T) = \exp\left(\sum_{k\geq 1} \#X(\mathbb{F}_{q^k})\frac{T^k}{k}\right).\]

Projective hypersurfaces

For a projective hypersurface, the middle-cohomology L-polynomial $P_m(T)$ is the only interesting factor. This factor is computed by zeta_coefficients. With the convention used here,

\[Z(X,T) = \frac{P_m(T)^{(-1)^{m+1}}}{\prod_{i=0}^{m}(1-q^iT)}.\]

Coefficient vectors are written in descending powers of $T$; the last entry of the raw vector is the constant coefficient 1. For example, the output [7, 1, 1] corresponds to the polynomial

\[7T^2 + T + 1.\]

For the methods below which take as input a homogeneous polynomial $f$, a nonsmooth hypersurface currently produces false.

API

DeRham.zeta_coefficients — Function
zeta_coefficients(f; S=[-1], verbose=0, changef=true, givefrobmat=false,
                  algorithm=:default, use_gpu=false, use_threads=false)

Computes zeta coefficients for the projective hypersurface defined by the homogeneous Oscar polynomial $f$ over a finite field of characteristic $p$. The returned vector contains the coefficients of the middle-cohomology L-polynomial in descending powers of $T$, as ZZRingElems, with constant coefficient 1 last. If $f$ is not smooth, the polynomial-based method returns false.

Keyword arguments:

  • S=[-1]: controls the S-smooth model used by the reduction; the default sentinel expands to all indices 0:n, where n is the dimension of the ambient projective space.
  • verbose=0: controls diagnostic output; zero prints nothing and larger values print progressively more detail.
  • changef=true: if the input is not an S-smooth model, allows the algorithm to try a random change of variables to find one. With false, or if no suitable model is found, the method returns false.
  • givefrobmat=false: if true, returns (F, coeffs), the Frobenius matrix and the coefficient vector, instead of just the coefficient vector.
  • algorithm=:default: selects the controlled-reduction algorithm; :default chooses automatically.
  • use_gpu=false: enables GPU execution for supported operations.
  • use_threads=false: enables threaded execution for supported operations.

The termorder, vars_reversed, fastevaluation, always_use_bigints, context, and precision_info keywords are internal or experimental and may change. Their current defaults are :invlex, false, true, false, nothing, and nothing, respectively.

The returned coefficients can be passed to L_polynomial, zeta_function, and other coefficient-taking invariants.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> DeRham.zeta_coefficients(f)
3-element Vector{ZZRingElem}:
 7
 1
 1

a wrapper to zeta_coefficients

  • "f" – Oscar polynomial (should be homogeneous) over the integers
  • "p" – a prime number, integer

DeRham.zeta_coefficients_with_precision — Function
zeta_coefficients_with_precision(f, r::Integer; basis=nothing, verbose=0, kwargs...)

Compute the zeta coefficients for the hypersurface defined by $f$, using $r$ as a requested relative $p$-adic precision for every Hodge component. This scalar overload applies the same request to all components. The algorithm combines the requested precision with its automatically computed minimum.

  • f: homogeneous polynomial over a finite field.
  • r: requested relative precision, repeated across the Hodge components.
  • basis: optional cohomology basis; the package computes one by default.
  • verbose: diagnostic verbosity.
  • kwargs...: keywords forwarded to zeta_coefficients.

Returns the descending ZZRingElem coefficient vector, or false when no smooth model is found.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> length(DeRham.zeta_coefficients_with_precision(f, 1))
3
source
zeta_coefficients_with_precision(f, r_m::AbstractVector; basis=nothing, verbose=0, kwargs...)

Vector-precision overload of zeta_coefficients_with_precision. r_m gives one requested relative precision for each Hodge component and must have the length required by the basis. The algorithm takes the componentwise maximum of these requests and its automatically computed minimum. The return value and other keywords are the same as for the scalar overload.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> length(DeRham.zeta_coefficients_with_precision(f, [1, 1]))
3

DeRham.zeta_function — Function
zeta_function(coeffs, q, m)

Given the raw, tate_twist or normalized_tate_twist descending coefficients coeffs of the middle ($H^m$) L-polynomial $P(T)$ of a smooth $m$-dimensional hypersurface $X$ over $\mathbb{F}_q$, returns the zeta function $Z(X, T) = P(T)^{(-1)^{m+1}} / \prod_{i=0}^{m} (1 - q^i T)$ as an element of fraction_field(ZZ[T]).

  • coeffs: descending coefficients of the middle L-polynomial.
  • q: size of the base finite field.
  • m: dimension of the hypersurface.

Examples

If you already have the coefficients, pass them with the field size and dimension:

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> coeffs = DeRham.zeta_coefficients(f);

julia> DeRham.zeta_function(coeffs, 7, 1)
(7*T^2 + T + 1)//(7*T^2 - 8*T + 1)
source
zeta_function(f; kwargs...)

zeta_function for the smooth hypersurface defined by the homogeneous polynomial $f$ (with $q$ the characteristic of parent(f) and m = nvars(parent(f)) - 2 its dimension), computed by calling zeta_coefficients(f; kwargs...) and delegating to the coefficient method. Returns false when $f$ is not smooth, matching zeta_coefficients. The result is an element of fraction_field(ZZ[T]).

  • f: homogeneous polynomial defining the hypersurface.
  • kwargs...: keywords forwarded to zeta_coefficients.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> DeRham.zeta_function(f)
(7*T^2 + T + 1)//(7*T^2 - 8*T + 1)

DeRham.L_polynomial — Function
L_polynomial(coeffs; ring = nothing)

Builds the L-polynomial as an element of ZZ[T] from its descending zeta_coefficients-style coefficients coeffs (coeffs[i] is the coefficient of $T^{\deg + 1 - i}$, where $\deg$ is length(coeffs) - 1; the constant term coeffs[end] is 1 for raw input). Uses ring (an MPolyRing/PolyRing over ZZ or a compatible coefficient ring) if given, else constructs a fresh polynomial_ring(ZZ, "T").

  • coeffs: descending L-polynomial coefficients, such as the output of zeta_coefficients.
  • ring: optional polynomial ring in which to construct the result.

Returns the polynomial in the selected ring.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> coeffs = DeRham.zeta_coefficients(f);

julia> DeRham.L_polynomial(coeffs)
7*T^2 + T + 1

DeRham.point_counts — Function
point_counts(coeffs, q, m, k)

Given the raw, tate_twist or normalized_tate_twist descending coefficients coeffs of the middle ($H^m$) L-polynomial of a smooth $m$-dimensional hypersurface over $\mathbb{F}_q$, returns $[\#X(\mathbb{F}_q), \#X(\mathbb{F}_{q^2}), \ldots, \#X(\mathbb{F}_{q^k})]$ via $\#X(\mathbb{F}_{q^i}) = \sum_{t=0}^{m} q^{t i} + (-1)^m p_i$, where $p_i$ is the $i$-th power sum of the middle-cohomology Frobenius eigenvalues (Newton identities on coeffs, in exact integer arithmetic).

  • coeffs: descending coefficients of the middle L-polynomial; raw, Tate twisted, and normalized Tate-twisted coefficients are accepted.
  • q: size of the base finite field.
  • m: dimension of the hypersurface.
  • k: number of extension-field counts to return.

Returns a vector of exact integer point counts, in order from $\mathbb{F}_q$ through $\mathbb{F}_{q^k}$.

Examples

If you already have the coefficients, pass them with the field size, dimension, and number of extension fields:

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> coeffs = DeRham.zeta_coefficients(f);

julia> DeRham.point_counts(coeffs, 7, 1, 2)
2-element Vector{ZZRingElem}:
  9
 63
