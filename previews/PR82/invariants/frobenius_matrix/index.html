Frobenius matrix

Projective Hypersurfaces

Let $X$ be a projective hypersurface over $\mathbb{F}_p$ of dimension $n$. We compute the Frobenius matrix on crystalline cohomology:

\[F \colon H^n_{\mathrm{crys}}(X/\mathbb{Z}_p) \to H^n_{\mathrm{crys}}(X/\mathbb{Z}_p)\]

The absolute Frobenius of $X$ induces $F$ by functoriality. DeRham computes the Frobenius matrix on the primitive part of middle cohomology; for a K3 surface, this gives a $21\times 21$ matrix. The module $H^n_{\mathrm{crys}}$ is a finitely generated $\mathbb{Z}_p$-module, free for a smooth hypersurface with rank equal to the middle Betti number; the matrix is the matrix of $F$ in a $\mathbb{Z}_p$-basis.

Because this matrix lives over $\mathbb{Z}_p$, we can only compute an approximation modulo $p^N$ for some $N$.

Our algorithm actually gives something much nicer; we give a basis for $H^n_{\mathrm{crys}}$ which is ordered by the Hodge filtration. Furthermore, for a basis element $e_{i,m} \in \mathrm{Fil}^m H^n_{\mathrm{crys}}$, we have the strong Mazur divisibility property:

\[F(e_{i,m}) \in p^{m} H^n_{\mathrm{crys}}.\]

This is very strong and uses many special properties, including the fact that hypersurfaces are liftable and Mazur–Ogus, the computation of de Rham cohomology of hypersurfaces due to Griffiths–Dwork, various comparison theorems in characteristic zero, and a delicate argument in Abbott–Kedlaya–Roe which compares the integral lattice in the Griffiths–Dwork basis to the lattice of crystalline cohomology in rigid cohomology.

However, what we get is that our Frobenius matrix has the strong Mazur divisibility. For example, for a genus 3 curve, the Frobenius matrix on $H^1_{\mathrm{crys}}$ has the form

\[\begin{pmatrix} p\ast & p\ast & p\ast & \ast & \ast & \ast \\ p\ast & p\ast & p\ast & \ast & \ast & \ast \\ p\ast & p\ast & p\ast & \ast & \ast & \ast \\ p\ast & p\ast & p\ast & \ast & \ast & \ast \\ p\ast & p\ast & p\ast & \ast & \ast & \ast \\ p\ast & p\ast & p\ast & \ast & \ast & \ast \end{pmatrix}\]

where each $\ast$ denotes an element of $\mathbb{Z}_p$.

When we compute the Frobenius matrix, we always compute each vector with a precision relative to the p-adic valuations guaranteed to us by strong Mazur divisibility. Thus, if we choose relative precision $r = 2$ for our curve of genus 3, the first three vectors will be computed modulo $p^3$ and the second three will be computed modulo $p^2$. If what you cared about was the absolute precision (i.e. the whole matrix modulo $p^2$), you can reduce the answer modulo $p^2$.

We also provide the option to choose a relative precision for each basis vector. DeRham.frobenius_matrix_with_precision computes the returned matrix with at least the requested relative precision for each Hodge-filtered piece. An existing automatic table floor can provide more. The certified truncation argument is summarized below. The full proof, “Certified series precision: proof of the fixed algorithm,” is not included in this repository; see dr-eevm.1 for the proof report.

For nonzero precision requests, each column retains its own parent ring and modulus in a FrobeniusMatrix. Use parent(FM[i, j]) to inspect an entry's modulus; column parents can differ. Generic matrix operations that assume a single coefficient ring may fail. Use DeRham.frobenius_matrix_in_ring(FM, R) to copy entries into a chosen common ring, which reduces all columns to that common precision.

Certified series truncation

Here $n$ is DeRham's ambient projective dimension, $p$ is prime, $m$ is a pole order from $1$ to $n$, and $r_m$ is its requested relative precision. Assume a smooth hypersurface and smooth lift with the AKR monomial basis and Frobenius normalization. The repaired AKR bound $A(t)$ is an upper bound for the H-lattice defect and is pointwise at most $f_0(t) = \sum_{j=1}^{n} \lfloor \log_p(\max(1,t-j)) \rfloor$. For the coordinate lattice, set $c = 0$ when $p \ge n$ and $c = v_p((n-1)!)$ when $p < n$; the lattice comparison gives the upper bound $B_V(t) = A(t) + c$.

For a proposed tail cutoff $T$, the implementation checks, using integer arithmetic, that $m+T \ge 2n+1$, that $E = m-1+T-r_m-c \ge 0$, and that $(p(m+T)-1)^n \le p^E$. The AKR bound and the floor-log estimate imply $B_V(p(m+i)) \le c + n\log_p(p(m+i)-1)$. Define $h(u) = m-1+u-r_m-c-n\log_p(p(m+u)-1)$. The integer checks give $h(T) \ge 0$; for every $u \ge T$ with $m+u \ge 2n+1$, $h'(u) = 1 - n/((m+u-1/p)\ln p) > 0$. Therefore $m-1+i-B_V(p(m+i)) \ge r_m$ for every integer $i \ge T$.

The selector checks the same inequality exactly for every $i < T$ using the repaired bound. This gives a candidate retained-term count: one more than the largest failing index, or zero if no index fails. The public count $N_m$ is raised to the Hodge-bound minimum $n-m+1$, so it can be positive even when there is no failing index. Every omitted term $i \ge N_m$ then satisfies the inequality, which is Costa's truncation condition. Such a $T$ always exists; the proof gives $T \le \max\{16n^2, 2(r_m+c+1), m\}-m$. Raising $N_m$ to an existing table floor preserves the certificate. The AKR lattice correction requires the specified integral basis hypotheses; an arbitrary rational basis is not covered. For zero requests with $p < n$, the API raises ArgumentError; for $p \ge n$, an all-zero request returns the Hodge-bound zero matrix.

DeRham.frobenius_matrix_with_precision — Function
frobenius_matrix_with_precision(f, r::Integer; basis=nothing, verbose=0, kwargs...)

Compute the Frobenius matrix for the smooth hypersurface defined by $f$ to the requested relative $p$-adic precision $r$. The scalar request is applied to every Hodge-filtered piece. The returned matrix meets at least this relative precision for each piece; an existing automatic table floor can provide more. The finite-tail certificate is documented in the Frobenius matrix precision proof, based on the full proof report, “Certified series precision: proof of the fixed algorithm.” Unless basis is supplied, the matrix is expressed in the internal cohomology basis computed by get_basis_of_cohomology(f); that helper and its basis ordering are not public API. Additional keywords are forwarded to zeta_coefficients.

For nonzero precision requests, the returned FrobeniusMatrix stores each column in its own parent ring to preserve that column's modulus. Use parent(FM[i, j]) to inspect an entry's modulus; column parents can differ. Generic matrix operations that assume a single coefficient ring may fail. Use frobenius_matrix_in_ring(FM, R) to copy entries into a chosen common ring, which reduces all columns to that common precision.

  • f: homogeneous polynomial defining the hypersurface.
  • r: requested relative $p$-adic precision for each Hodge-filtered piece.
  • basis: optional basis to use instead of computing the default basis.
  • verbose: diagnostic verbosity, forwarded to the computation.
  • kwargs...: additional keywords forwarded to zeta_coefficients.

Returns the Frobenius matrix, or false if the input does not meet the required smoothness condition.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> size(DeRham.frobenius_matrix_with_precision(f, 2))
(2, 2)

Vector-precision overload of frobenius_matrix_with_precision. r_m gives one requested relative $p$-adic precision for each Hodge-filtered piece and must have the length required by the selected basis. DeRham.FrobeniusMatrix — Type
FrobeniusMatrix

An AbstractMatrix whose columns may have different coefficient rings. Entry access preserves each column's parent ring; use frobenius_matrix_in_ring when an operation requires one common ring.

DeRham.frobenius_matrix_in_ring — Function
frobenius_matrix_in_ring(FM, R)

Copies a Frobenius matrix into a single coefficient ring R, lifting each entry before coercion. This is useful when a matrix operation requires one common coefficient ring; the requested ring determines the retained precision.
