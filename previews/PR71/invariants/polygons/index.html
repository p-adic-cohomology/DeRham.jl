Newton & Hodge polygons

For a smooth hypersurface over a finite field, the Newton polygon records the p-adic valuations of the Frobenius eigenvalues on primitive middle cohomology. If its L-polynomial is P(T) = c_d T^d + \cdots + c_0 = \prod_i (1 - \alpha_i T), the Newton polygon is the lower convex hull of the coefficient points (i, v_p(c_i)); its slopes are the valuations of the reciprocal roots \alpha_i. Coefficient vectors passed to DeRham are in descending order.

The Hodge polygon records the Hodge numbers of that cohomology. For a smooth degree-d hypersurface in P^n, the horizontal length at slope r is h^{n-1-r,r}, for r = 0, \ldots, n-1. Both functions return a SlopesPolygon, which stores the slopes and their horizontal lengths starting from (0, 0); see Utilities.

DeRham.newton_polygon — Function
newton_polygon(coeffs, p)

Given the raw, tate_twist, or normalized_tate_twist descending coefficients coeffs of an L-polynomial, returns its Newton polygon. The coefficients are normalized to the raw convention before the lower convex hull of the points (i, v_p(c_i)) is formed; the slopes are the p-adic valuations of the reciprocal roots.

  • coeffs: descending L-polynomial coefficients.
  • p: prime characteristic used for the p-adic valuation.

Returns a SlopesPolygon whose slopes and horizontal lengths encode the Newton polygon.

If you already have zeta_coefficients output for a curve, pass it with its characteristic:

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> coeffs = DeRham.zeta_coefficients(f);

julia> DeRham.newton_polygon(coeffs, 7).slopes == [0//1, 1//1]
true

newton_polygon(f; kwargs...)

newton_polygon for the smooth hypersurface defined by the homogeneous polynomial f. It obtains the characteristic p from parent(f), calls zeta_coefficients(f; kwargs...), and delegates to the coefficient method.

  • f: homogeneous polynomial defining the hypersurface.
  • kwargs...: keywords forwarded to zeta_coefficients.

Returns a SlopesPolygon, or false when f is not smooth, matching zeta_coefficients.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> DeRham.newton_polygon(f).slopes == [0//1, 1//1]
true

DeRham.hodge_polygon — Function
hodge_polygon(n, d)

Hodge polygon of the primitive middle cohomology of a smooth hypersurface of degree d in P^n: the SlopesPolygon of Hodge numbers h^{n-1-p, p}, given in closed form by the coefficient of t^((p+1)d - n - 1) in the Jacobian ring's Hilbert series (1 + t + ... + t^(d-2))^(n+1), for p = 0, ..., n - 1.

  • n: dimension of the ambient projective space.
  • d: degree of the hypersurface.

Returns a SlopesPolygon. The slope p has horizontal length h^{n-1-p,p}.

For example, a smooth plane cubic has Hodge numbers (1, 1):

julia> DeRham.hodge_polygon(2, 3).slopelengths == [1, 1]
true
source
hodge_polygon(f; basis=nothing, params=default_params())

Hodge polygon of the primitive middle cohomology of the smooth hypersurface defined by the homogeneous polynomial f.

  • f: homogeneous polynomial defining the hypersurface.
  • basis: optional precomputed cohomology basis. If omitted, a basis is constructed from f.
  • params: series-precision parameters used when constructing the basis; ignored when basis is supplied.

Returns a SlopesPolygon, with one slope for each Hodge number.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> DeRham.hodge_polygon(f).slopelengths == [1, 1]
true
