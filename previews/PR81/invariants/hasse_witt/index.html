Hasse–Witt matrix & a-number

For a smooth plane curve $C$ of genus $g$ over $\mathbb{F}_p$, the Hasse–Witt matrix represents Frobenius on $H^1(C, \mathcal{O}_C)$ in the basis used by the Frobenius computation. DeRham obtains it by reducing the final $g \times g$ block of a precision-1 Frobenius matrix modulo $p$. See the Frobenius matrix page for that matrix and its precision.

The curve's a-number is $g - \operatorname{rank}(H)$, where $H$ is the Hasse–Witt matrix. For an elliptic curve, a full-rank matrix gives the ordinary case and a zero matrix gives the supersingular case.

The Fermat cubic over $\mathbb{F}_7$ is ordinary because 7 is congruent to 1 modulo 3. The Fermat cubic over $\mathbb{F}_5$ is supersingular because 5 is congruent to 2 modulo 3:

julia> using DeRham, Oscar

julia> f7 = DeRham.fermat_hypersurface(3, 3, 7);

julia> FM7 = DeRham.frobenius_matrix_with_precision(f7, [1, 0]);

julia> H7 = DeRham.hasse_witt_matrix(FM7, 1);

julia> (rank(H7), DeRham.a_number(FM7, 1))
(1, 0)

julia> f5 = DeRham.fermat_hypersurface(3, 3, 5);

julia> FM5 = DeRham.frobenius_matrix_with_precision(f5, [1, 0]);

julia> H5 = DeRham.hasse_witt_matrix(FM5, 1);

julia> (rank(H5), DeRham.a_number(FM5, 1))
(0, 1)

API

DeRham.hasse_witt_matrix — Function
hasse_witt_matrix(FM, h)

Given a Frobenius matrix FM computed at relative precision 1 and the curve's genus $h$, returns the Hasse-Witt matrix: the last $h \times h$ block of FM, reduced modulo $p$. Here $p$ is the unique prime factor of the modulus of base_ring(FM).

  • FM: Frobenius matrix over a ring with prime-power modulus, computed at precision 1.
  • h: genus of the curve, which is the size of the Hasse-Witt matrix.

Returns an $h \times h$ matrix over $\mathbb{F}_p$.

If you already have a Frobenius matrix, pass it with the curve's genus:

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> FM = DeRham.frobenius_matrix_with_precision(f, [1, 0]);

julia> size(DeRham.hasse_witt_matrix(FM, 1))
(1, 1)
source
hasse_witt_matrix(f; verbose = 0, kwargs...)

Hasse-Witt matrix of the smooth plane curve defined by the homogeneous polynomial $f$, computed via frobenius_matrix_with_precision(f, r_m; kwargs...) with r_m = [1, 0].

  • f: homogeneous polynomial in three variables defining the curve.
  • verbose: diagnostic verbosity forwarded to the Frobenius computation.
  • kwargs...: additional keywords forwarded to frobenius_matrix_with_precision and its coefficient computation.

Returns a matrix over $\mathbb{F}_p$, where $p$ is the characteristic of the field. For a curve of genus $g$, the matrix is $g \times g$.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> rank(DeRham.hasse_witt_matrix(f))
1

DeRham.a_number — Function
a_number(FM, h)

For a smooth curve, returns the dimension of the kernel of its Hasse-Witt matrix $H$: $h - \operatorname{rank}(H)$.

  • FM: Frobenius matrix computed at relative precision 1.
  • h: genus of the curve.

Returns the curve's a-number as an integer.

If you already have a Frobenius matrix, pass it with the curve's genus:

julia> f = DeRham.fermat_hypersurface(3, 3, 5);

julia> FM = DeRham.frobenius_matrix_with_precision(f, [1, 0]);

julia> DeRham.a_number(FM, 1)
1
source
a_number(f; verbose = 0, kwargs...)

Computes the a-number of the smooth plane curve defined by the homogeneous polynomial $f$, via its Hasse-Witt matrix. This method is currently supported only for curves.

  • f: homogeneous polynomial in three variables defining the curve.
  • verbose: diagnostic verbosity forwarded to the Frobenius computation.
  • kwargs...: additional keywords forwarded to frobenius_matrix_with_precision and its coefficient computation.

Returns the curve's a-number as an integer.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 5);

julia> DeRham.a_number(f)
1
