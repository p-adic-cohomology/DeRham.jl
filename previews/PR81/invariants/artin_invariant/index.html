Artin invariant

Let $X$ be a supersingular K3 surface over a field of characteristic $p > 2$, i.e. one of infinite Artin–Mazur height. Then the Néron–Severi lattice of $X_{\bar{k}}$ has rank $22$ and discriminant $-p^{2\sigma}$ for an integer $1 \le \sigma \le 10$. This integer $\sigma$ is the Artin invariant of $X$.

DeRham.artin_invariant — Function
artin_invariant(f::MPolyRingElem; kwargs...)
artin_invariant(F::MatElem)

Compute the Artin invariant $σ$ of a supersingular quartic K3 surface from its Frobenius matrix modulo $p²$. The computation uses linear algebra over $𝔽_p$ on primitive $H²$. The matrix method returns a plain Int; the polynomial method returns a plain Int on success, or false if its Frobenius computation rejects the polynomial as non-smooth.

Supersingularity is a precondition and is not checked. A non-supersingular input, such as an ordinary quartic, can produce an incorrect value or an assertion error. The polynomial method requires a homogeneous quartic in four variables over the prime field $𝔽_p$ for an odd prime. It computes the Frobenius matrix with relative precision [0, 1, 2] and forwards keyword arguments to frobenius_matrix_with_precision. It returns false if that computation rejects the polynomial as non-smooth.

The matrix method requires a 21×21 Frobenius matrix over $ℤ/p^M$ with odd prime $p$ and $p²$ dividing the modulus. Its first column must be divisible by $p²$ in the chosen pole-order basis.

The algorithm is from forthcoming work of Bhamidipati, Broe, Garzella, Nair, Pagano, and Zhang.

Examples

A supersingular quartic over $𝔽_3$ with Artin invariant 2:

julia> R, (x, y, z, w) = polynomial_ring(GF(3), ["x", "y", "z", "w"]);

julia> f = x^4 + y^3*z + y*z^3 + x*y^2*w + w^4;

julia> DeRham.artin_invariant(f)
2
