Jacobians

Let $C$ be a smooth plane curve over $\mathbb{F}_q$, with genus $g$, and let $J = \operatorname{Jac}(C)$. The Jacobian's first cohomology agrees with the curve's, so both have the same $H^1$ L-polynomial $P_C(T) = \prod_{j=1}^{2g}(1 - \alpha_j T)$. This is the coefficient vector returned by jacobian_zeta_coefficients.

The Jacobian's higher cohomology is formed from exterior powers of $H^1(C)$. For each $i$, the Frobenius eigenvalues on $H^i(J) = \wedge^i H^1(C)$ are products of $i$ distinct $\alpha_j$, so the zeta function is

\[Z(J,T) = \prod_{i=0}^{2g} P_i(T)^{(-1)^{i+1}}, \qquad P_i(T) = \prod_{1 \leq j_1 < \cdots < j_i \leq 2g} (1 - \alpha_{j_1} \cdots \alpha_{j_i} T).\]

The point counts are obtained from the curve's Frobenius eigenvalues:

\[\#J(\mathbb{F}_{q^k}) = \prod_{j=1}^{2g}(1 - \alpha_j^k).\]

For example, a Fermat quartic in three variables over $\mathbb{F}_5$ defines a smooth genus-three curve:

julia> using DeRham, Oscar

julia> f = DeRham.fermat_hypersurface(3, 4, 5);

julia> length(DeRham.jacobian_zeta_coefficients(f))
7

julia> length(DeRham.jacobian_point_counts(f, 2))
2

API

DeRham.jacobian_zeta_coefficients — Function
jacobian_zeta_coefficients(f; kwargs...)

The $H^1$ zeta_coefficients of the Jacobian $J$ of the smooth plane curve $C$ defined by the homogeneous polynomial $f$, i.e. zeta_coefficients(f; kwargs...), since $H^1(J) = H^1(C)$. There is no data form, since it would be the identity. Throws ArgumentError when $f$ does not define a plane curve.

  • f: homogeneous polynomial in three variables defining the curve.
  • kwargs...: keywords forwarded to zeta_coefficients.

Returns the descending coefficient vector of the curve's $H^1$ L-polynomial, or false when $f$ is not smooth.

Examples

julia> f = DeRham.fermat_hypersurface(3, 4, 5);

julia> length(DeRham.jacobian_zeta_coefficients(f))
7

DeRham.jacobian_point_counts — Function
jacobian_point_counts(coeffs, q, k)

Given the raw, tate_twist or normalized_tate_twist descending coefficients coeffs of the $H^1$ L-polynomial of a smooth curve over $\mathbb{F}_q$ ($H^1(J) = H^1(C)$ for its Jacobian $J$), returns $[\#J(\mathbb{F}_q), \#J(\mathbb{F}_{q^2}), \ldots, \#J(\mathbb{F}_{q^k})]$ via $\#J(\mathbb{F}_{q^i}) = L_i(1) = \prod_j (1 - \alpha_j^i)$, with $L_i$ built exactly from the $\alpha_j^i$ power sums via Newton's identities, in exact integer arithmetic.

  • coeffs: descending coefficients of the curve's $H^1$ L-polynomial; raw, Tate-twisted, and normalized Tate-twisted coefficients are accepted.
  • q: size of the base finite field.
  • k: number of extension fields to count.

Returns a vector of exact integer point counts for the Jacobian, from $\mathbb{F}_q$ through $\mathbb{F}_{q^k}$.

If you already have zeta_coefficients output for a curve, pass it with the field size and number of extensions:

julia> f = DeRham.fermat_hypersurface(3, 4, 5);

julia> coeffs = DeRham.zeta_coefficients(f);

julia> length(DeRham.jacobian_point_counts(coeffs, 5, 2))
2
source
jacobian_point_counts(f, k; kwargs...)

jacobian_point_counts for the Jacobian $J$ of the smooth plane curve defined by the homogeneous polynomial $f$ (with $q$ the characteristic of parent(f)), computed by calling zeta_coefficients(f; kwargs...) and delegating to the coefficient method. Returns false when $f$ is not smooth, matching zeta_coefficients. Throws ArgumentError when $f$ does not define a plane curve.

  • f: homogeneous polynomial in three variables defining the curve.
  • k: number of extension fields to count.
  • kwargs...: keywords forwarded to zeta_coefficients.

Returns a vector of exact integer point counts for the Jacobian, or false when $f$ is not smooth.

Examples

julia> f = DeRham.fermat_hypersurface(3, 4, 5);

julia> length(DeRham.jacobian_point_counts(f, 2))
2

DeRham.jacobian_zeta_function — Function
jacobian_zeta_function(coeffs, q)

Given the raw, tate_twist or normalized_tate_twist descending coefficients coeffs of the $H^1$ L-polynomial of a smooth genus-$g$ curve over $\mathbb{F}_q$ ($H^1(J) = H^1(C)$ for its Jacobian $J$), returns $Z(J, T) = \prod_{i=0}^{2g} P_i(T)^{(-1)^{i+1}}$, where $P_i$ is the characteristic polynomial of Frobenius on $\wedge^i H^1$, as an element of fraction_field(ZZ[T]). Warns when $g > 10$, since the cost grows like $\binom{2g}{g}$.

  • coeffs: descending coefficients of the curve's $H^1$ L-polynomial; raw, Tate-twisted, and normalized Tate-twisted coefficients are accepted.
  • q: size of the base finite field.

Returns the Jacobian's zeta function in fraction_field(ZZ[T]).

If you already have zeta_coefficients output for a curve, pass it with the field size:

julia> f = DeRham.fermat_hypersurface(3, 4, 5);

julia> coeffs = DeRham.zeta_coefficients(f);

julia> zeta = DeRham.jacobian_zeta_function(coeffs, 5);

julia> (degree(numerator(zeta)), degree(denominator(zeta)))
(32, 32)
source
