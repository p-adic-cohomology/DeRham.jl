Utilities

These helpers are public but are not exported. Call them with the DeRham. prefix.

Hypersurfaces

DeRham.fermat_hypersurface — Function
fermat_hypersurface(n, d, p)

Construct the Fermat hypersurface polynomial x₁^d + ⋯ + xₙ^d over the finite field GF(p). It has n variables and defines a hypersurface of dimension n - 2 in projective space.

  • n: number of variables.
  • d: degree.
  • p: prime characteristic of the coefficient field.

Returns the homogeneous Oscar polynomial.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> total_degree(f)
3
source
DeRham.random_hypersurface — Function
random_hypersurface(n, d, p)

Construct a homogeneous degree-d polynomial in n variables over GF(p), with independent uniform random coefficients for its degree-d terms. It defines a hypersurface of dimension n - 2 in projective space.

  • n: number of variables.
  • d: degree of the terms.
  • p: prime characteristic of the coefficient field.

Returns the Oscar polynomial. The result is random and is not guaranteed to define a smooth hypersurface.

Examples

julia> f = DeRham.random_hypersurface(3, 3, 7);

julia> nvars(parent(f))
3
source
DeRham.check_smoothness — Function
check_smoothness(f)

Check whether the homogeneous Oscar polynomial f defines a smooth hypersurface over its coefficient field.

f must already be homogeneous; Oscar may throw an error otherwise. The result is a Bool.

This wrapper is named check_smoothness because Oscar already provides is_smooth.

Examples

julia> f = DeRham.fermat_hypersurface(3, 3, 7);

julia> DeRham.check_smoothness(f)
true
source

Slope polygons

SlopesPolygon stores the slopes and lengths of a polygon starting at (0, 0). Its integer-vector constructor uses slopes 0, 1, 2, ... with the corresponding entries giving their horizontal lengths. The two-vector constructor takes points (xs[i], yvals[i]) and forms their lower convex hull.

DeRham.SlopesPolygon — Type
SlopesPolygon(slopelengths)
SlopesPolygon(xs, yvals)
SlopesPolygon(vertices)

Represent a piecewise-linear polygon starting at (0, 0). The integer-vector constructor uses slopes 0, 1, 2, ...; each entry of slopelengths is the horizontal length for the corresponding slope. For example, SlopesPolygon([1, 19, 1]) is the Hodge polygon of the primitive second cohomology of a K3 surface.

The two-vector constructor takes points (xs[i], yvals[i]) with xs sorted in ascending order and constructs their lower convex hull. The vertices constructor takes the polygon's vertices, including the initial (0, 0).

The object stores its slopes, their lengths, the values at integer coordinates, and the slope immediately before each coordinate. Indexing with sp[x] returns the polygon's value at the integer coordinate x.

Returns a SlopesPolygon value. Its representation is computed eagerly.

Examples

julia> polygon = DeRham.SlopesPolygon([1, 19, 1]);

julia> polygon[2] == 1
true

Tate twists

For a coefficient vector describing P(T) = c₀T^d + ⋯ + c_d, tate_twist returns the coefficients of P(T/q^j), tate_untwist reverses that substitution (and an optional normalization), and normalized_tate_twist returns the coefficients of q^s P(T/q^j). These helpers keep the descending coefficient order.

DeRham.tate_twist — Function
tate_twist(coeffs, q; j = 1)

Given the descending zeta_coefficients-style coefficients coeffs of an L-polynomial P(T), returns the coefficients (same orientation, as QQFieldElem, ending in 1) of the Tate twist P(T / q^j).

  • coeffs: coefficients of P(T) in descending powers.
  • q: size of the base finite field.
  • j: twist exponent.

Returns an exact rational coefficient vector.

Examples

julia> raw = [7, -2, 1];

julia> DeRham.tate_twist(raw, 7)
3-element Vector{QQFieldElem}:
  1//7
 -2//7
  1
source
DeRham.tate_untwist — Function
tate_untwist(coeffs, q; j = 1, s = 0)

Inverts both a Tate twist and a normalization: divides coeffs by q^s, then returns the coefficients (as ZZRingElem) of P(q^j T), where P is the L-polynomial with coefficients coeffs / q^s. Throws ArgumentError if the result is not integral.

  • coeffs: coefficients in descending powers.
  • q: size of the base finite field.
  • j: twist exponent to undo.
  • s: normalization exponent to undo.

Returns an exact integer coefficient vector.

Examples

julia> raw = [7, -2, 1];

julia> DeRham.tate_untwist(DeRham.tate_twist(raw, 7), 7)
3-element Vector{ZZRingElem}:
  7
 -2
  1
source
DeRham.normalized_tate_twist — Function
normalized_tate_twist(coeffs, q, s; j = 1)

Given the descending zeta_coefficients-style coefficients coeffs of an L-polynomial P(T), returns the coefficients (as ZZRingElem) of q^s * P(T / q^j). Throws ArgumentError if that is not integral. With s = 1, j = 1 this is the old "boat shape" L-polynomial. Note: a normalized twist with s = 0 is indistinguishable from raw coefficients and cannot be distinguished from raw coefficients by the coefficient-input detection used by the invariant functions.

  • coeffs: coefficients of P(T) in descending powers.
  • q: size of the base finite field.
  • s: normalization exponent.
  • j: twist exponent.

Returns an exact integer coefficient vector.

Examples

julia> DeRham.normalized_tate_twist([7, -2, 1], 7, 1)
3-element Vector{ZZRingElem}:
  1
 -2
  7
